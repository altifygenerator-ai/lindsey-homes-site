# Lindsey Homes lead automation options

This file is project documentation only. It is not exposed on the website.

## Recommended first step: branded automatic acknowledgment

On a successful website inquiry:

1. Keep sending the full lead details to Whitney.
2. Immediately send the customer a branded Lindsey Homes acknowledgment from the verified Lindsey Homes domain.
3. Personalize it with the customer's name and, when useful, their build location / property status.
4. Set Reply-To to Whitney so any response goes directly to her.
5. Keep the copy short and high-touch rather than making it feel like a marketing sequence.

This does not require AI and fits a luxury lead experience better than a long automated sales funnel.

Suggested build add-on: roughly $150.

## Expanded follow-up automation

Possible additions:

- save leads to Supabase
- send immediate acknowledgment
- send one carefully written follow-up after a chosen delay
- stop future follow-ups once the lead is marked contacted
- secure one-click internal links for lead status without building a full admin dashboard
- delivery / failure logging

Suggested build add-on: roughly $250–$350 depending on follow-up rules and tracking.

## Fully intelligent / conversational automation

A system that reads inbound replies and automatically writes or sends contextual responses is a separate feature. It would need inbound email handling, thread storage, reply rules, handoff rules, logging, and strong limits on what the system is allowed to answer without a person.

Suggested build add-on: roughly $500+ depending on how autonomous it is.

For Lindsey Homes, the safest fit is the first option: an immediate polished acknowledgment followed by Whitney personally handling the lead.
